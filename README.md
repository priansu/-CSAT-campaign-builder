# Pulse — CSAT Campaign Builder

A polished, responsive React/Vite implementation of the AppVersal frontend intern assignment.

## What it includes

- Content configuration for initial feedback, rating options, comments and thank-you state
- Dynamic add/delete rating options
- Styling controls for colors, typography, radius and button sizing
- Real-time mobile preview with no save/refresh required
- Interactive rating and thank-you flow inside the preview
- Responsive layout for desktop and mobile
- Polished light/dark theme switcher with saved preference
- Clean reusable React components
- No backend required

## Tech stack

- React 18
- Vite
- JavaScript
- CSS
- Lucide React icons

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Production build

```bash
npm run build
npm run preview
```

## Deploy

The project is Vercel/Netlify friendly. Import the repository, use `npm run build` as the build command, and serve the generated `dist` folder.

## Design direction

The UI intentionally treats the builder like a small product rather than a form: compact navigation, friendly copy, a strong live preview, subtle status feedback, and an interactive mobile experience.
